隱私權政策

說明 MyDrive 如何存取、使用、保存與移除你的資料。

生效與更新日期：2026 年 10 月 18 日 · 適用 MyDrive v2.0.1 桌面程式及此網站

MyDrive 是由 GitHub 維護者 bos-tw 維護的 Windows 雲端磁碟工具，提供 Google Drive 與 NAS 的檔案瀏覽、傳輸及磁碟掛載功能。本政策中的「MyDrive」指此專案及其原始桌面程式。

存取資料保存與保護使用與分享移除與撤銷網站資料

1. 存取哪些資料，以及用途

你選擇連接儲存服務後，MyDrive 會在你的電腦上透過對應服務與 rclone 引擎執行存取。MyDrive 不會向你索取 Google 帳戶密碼；Google 登入與同意授權在 Google 官方網頁進行。

Google Drive 連線所使用的資料
資料類型使用目的
OAuth 存取權杖與更新權杖向 Google Drive API 驗證授權，並在權杖正常到期時更新授權，以支援檔案操作及自動掛載。
Google Drive 帳戶識別碼確認重新登入的是相同 Google 帳戶，避免原帳戶與待上傳快取被替換到不同帳戶。
檔案與資料夾中繼資料列出檔案名稱、路徑、大小、時間、檔案類型與相關存取資訊，提供瀏覽及磁碟檔案系統。
檔案內容與服務回傳的儲存資訊依你的選擇下載、開啟、匯出、上傳、修改、移動或刪除檔案，以及提供儲存空間資訊。

你可選擇唯讀範圍 https://www.googleapis.com/auth/drive.readonly，以列出與下載 Drive 檔案；或選擇讀寫範圍 https://www.googleapis.com/auth/drive，以管理你有權限存取的 Drive 檔案，包括新增、修改及刪除。廣泛的檔案存取用於掛載既有 Drive 資料夾及其中的檔案。

在 MyDrive 選擇起始資料夾，只限制程式顯示及掛載的起始位置，並不縮小 Google 授予的 OAuth 範圍。Google 原生文件匯出功能僅在你啟用後顯示。

若連接 NAS，程式會依協定使用你輸入的伺服器地址、帳戶、密碼或相關連線設定。網路代理與自動啟動等設定由你選擇啟用。

2. 資料保存位置與保護方式

  • 帳戶設定：儲存服務帳密、Google OAuth 應用設定、權杖與帳戶識別資訊保存於本機加密的 accounts.conf，由你設定的帳戶保護密碼保護。
  • 一般設定：磁碟代號、帳戶代稱、掛載路徑、伺服器相關偏好及其他非密碼設定保存在本機設定檔；部分資訊可能屬於個人資料，請保護電腦與備份。
  • 記住解鎖與代理密碼：若你選擇保存，使用目前 Windows 帳戶的 DPAPI 保護。
  • 檔案快取：已讀取的內容及待上傳修改可能存放在本機快取。MyDrive 不會額外加密此快取；可透過 Windows 磁碟加密、帳戶權限與實體存取控制保護。
  • 本機記錄：故障排查記錄可能包含連線錯誤、服務主機、帳戶代稱、檔案路徑及傳輸資訊；程式不會自動將這些記錄傳給專案維護者。

免安裝版預設保存在程式旁的 data；安裝版預設保存在 %LOCALAPPDATA%\MyDrive。快取位置可在設定中變更。匯出的設定備份由你自行保管，代理密碼與此電腦的記住解鎖資料不隨設定備份移轉。

3. 資料使用、傳輸與分享

Google Drive 資料只用於你選擇的檔案存取、管理與磁碟掛載功能。原始 MyDrive 桌面程式沒有把雲端檔案或登入權杖集中儲存在維護者伺服器的功能，亦未內建廣告或使用者行為分析服務。

  • 連線會將完成驗證或檔案操作所需的資料傳送給 Google、你指定的 NAS 或儲存服務。Google OAuth 與 Drive API 使用 HTTPS。
  • 若你設定網路代理，相關流量會經過你指定的代理。NAS 連線的傳輸保護取決於你選擇的協定與憑證設定。
  • 若你自行設定更新資訊網址並按下檢查更新，程式會連接該網址；此功能不需要傳送 Google 權杖或雲端檔案。
  • 若你主動向維護者提供問題記錄或檔案，只有你選擇提供的內容會透過你採用的聯絡平台交付。請先移除權杖、密碼及不需要的個人內容。

MyDrive 不會出售 Google 使用者資料，不會將其用於廣告、建立廣告個人檔案、信用評估，或訓練通用人工智慧模型。專案維護者不會透過 MyDrive 自動取得或人工閱覽你的 Google Drive 檔案。

Google API Limited Use：MyDrive 使用從 Google API 取得的資訊，以及向其他應用程式移轉該資訊時，將遵守 Google API Services User Data Policy，包括 Limited Use 要求。

MyDrive’s use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

4. 保留、刪除與撤銷授權

帳戶及磁碟設定通常保留至你手動移除；快取依程式設定管理，待上傳的修改可能為保護資料而持續保留。解除安裝會保留個人資料，不會自動清空設定與快取。

  1. 停止存取：先完成上傳並關閉使用中的遠端檔案，在 MyDrive 中斷磁碟；必要時關閉該磁碟的自動掛載。
  2. 移除連線：移除使用該帳戶的磁碟設定，再於「儲存帳戶」移除帳戶。這會移除本機帳戶設定，不會刪除 Google Drive 檔案，亦不會自動撤銷 Google 端的授權。
  3. 撤銷 Google 授權：到 Google 帳戶的第三方連線管理，選擇對應應用並撤銷存取。MyDrive 之後需要你重新授權才能連線。
  4. 清除本機資料：確認沒有待上傳資料後，結束 MyDrive，再依需要刪除不再使用的設定、快取、記錄及你自行建立的備份。刪除前請確認遠端已收到需要保留的檔案。

你在 MyDrive 發出的 Google Drive 檔案刪除操作預設移至 Google Drive 垃圾桶。永久刪除、回復及服務端保留規則由 Google Drive 管理。

5. 此網站與第三方平台

此靜態網站不要求 Google 登入，不處理 OAuth 回呼，不提供檔案上傳表單，且未加入分析、廣告或追蹤指令碼。網站由 GitHub Pages 託管；GitHub 會基於安全等目的處理訪客 IP 等連線資料，詳見 GitHub 隱私權聲明。使用 GitHub 專案、問題回報或 Google 網頁時，亦適用各平台的資料處理規則。

6. 政策更新與聯絡

本政策會隨功能與資料處理方式調整，更新日期顯示於頁首。若新增不同用途的 Google 資料處理，將先更新揭露資訊，並在適用時重新取得你的同意。

資料處理問題可透過 MyDrive 專案問題回報 或 維護者 bos-tw 的 GitHub 個人頁面所列的聯絡方式聯繫。請勿在公開問題回報中貼上密碼、OAuth 權杖或私人檔案。
