服務條款

MyDrive 桌面程式與此專案網站的使用說明。

生效與更新日期：2026 年 10 月 18 日

1. 專案與功能範圍

MyDrive 由 GitHub 維護者 bos-tw 維護，是連接 Google Drive 與 NAS 的 Windows 桌面程式。檔案儲存在你選擇的儲存服務與本機快取中；MyDrive 專案本身不提供雲端檔案託管空間。

Google Drive、NAS 供應商、GitHub、rclone 與 WinFsp 各自提供其產品或服務。MyDrive 是獨立專案，未宣稱得到 Google 或 RaiDrive 的認可、贊助或合作授權。

2. 軟體授權

MyDrive 原創程式碼依 MIT License 提供，允許在遵守授權條件下使用、複製、修改與散布。散布時須保留適用的著作權及授權聲明。第三方元件依各自授權使用，詳見程式資料夾隨附的 THIRD-PARTY.txt 與各元件授權檔案。

3. 使用者的帳戶與檔案操作

  • 只連接你擁有或已獲授權使用的儲存帳戶，並遵守儲存服務的條款、配額與存取規則。
  • Google 讀寫授權可讓程式依你的操作新增、變更、移動與刪除檔案。若只需要瀏覽與下載，請選擇唯讀授權。
  • 本機磁碟模式提供檔案系統介面；遠端檔案的可用性與效能仍取決於網路及儲存服務。
  • 請保管帳戶保護密碼、電腦存取權及設定備份。檔案快取未由 MyDrive 額外加密。
  • 修改可能先寫入本機快取，再上傳至遠端。結束程式、清除快取或移除裝置前，請確認重要修改已完成上傳，並自行維護適當備份。

4. 第三方服務與授權變更

Google 與其他儲存服務可依其政策要求重新登入、限制請求或停止存取。Google OAuth 的正式發布、品牌驗證與範圍驗證是不同設定；提供此網站不表示 Google 已完成審核或授權永不失效。

WinFsp 是系統驅動，首次安裝可能需要 Windows 管理員權限。免安裝版主程式的設定可隨資料夾移動，但已安裝的系統驅動由 Windows 管理。

5. 隱私權與停止使用

資料存取、儲存與移除方式請參閱 隱私權政策。你可以中斷磁碟、關閉自動啟動及掛載、移除本機帳戶，並在 Google 帳戶連線管理撤銷授權。請先完成待上傳資料，再清除本機快取。

6. 保證與責任

軟體依 MIT 授權以「現狀」提供，在法律允許的範圍內不提供明示或默示保證；責任限制以適用的軟體授權及法律為準。此條款不排除依法不能排除的權利或責任。

7. 更新與聯絡

程式功能及本條款可能隨版本調整，更新日期顯示於頁首。使用問題可在 MyDrive GitHub 專案回報，或透過 維護者 bos-tw 的 GitHub 個人頁面所列的方式聯繫。
